# Reporting a vulnerability

Report suspected security vulnerabilities privately to **support@sentfrom.ai**.
Include the affected component or package version, the expected and actual
behavior, and a minimal reproduction using an isolated test account when possible.

Do not publish vulnerabilities involving customer information in a GitHub issue.
Do not send API keys, passwords, OAuth tokens, session cookies, or customer email
contents in your report. Redact credentials and personal information from logs
and screenshots. We can arrange an appropriate channel if additional sensitive
details are needed.

Directory and marketplace reviewers should use the platform's private test
credential mechanism with a dedicated review account. Never add a credential to
`server.json`, `glama.json`, source code, or a public review comment.
